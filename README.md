# 💻 Frontend Learning Progress

Bem-vindo(a) ao meu laboratório de estudos em Desenvolvimento Web! Este repositório foi criado para documentar minha jornada e evolução no ecossistema **Frontend**, partindo dos fundamentos até a stack front completa.

> **My frontend learning lab from basic (HTML, CSS, JS) to advanced (React + TypeScript + Tailwind).**

---

## Objetivo & Estratégia de Estudos

Como meu objetivo final é a formação **Fullstack**, adotei a estratégia de isolar os meus estudos por escopo para garantir um aprendizado sólido:

*   **Foco deste Repositório:** Dedicado *exclusivamente* à interface, design system, componentização e estado no Frontend.
*   **Back-end & Integrações:** Toda a parte de servidor, banco de dados e APIs está sendo estudada e implementada em **repositórios separados**.

---

## 📑 Trilha de Aprendizado

### 1. Fundamentos (Em Andamento )
*   **HTML:** Estruturação semântica e acessibilidade.
*   **CSS:** Estilização, Flexbox, Grid Layout e Responsividade.
*   **JavaScript:** Lógica, manipulação de DOM, Arrow Functions e requisições assíncronas.

### 2. Stack Avançada (Próximos Passos)
*   **React:** Componentização, Hooks e Single Page Applications (SPA).
*   **TypeScript:** Tipagem estática, interfaces e maior segurança no código.
*   **Tailwind CSS:** Produtividade extrema com classes utilitárias.
